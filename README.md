# Student Management System 🎓

## 📝 Description
A console-based **Student Management System** built using **Python**. This project uses file handling (`.txt` and `.csv`) to store, manage, and track student records without the need for an external database. It includes a comprehensive menu with 17 different administrative operations.

## ✨ Key Features
- [cite_start]**Admin Authentication:** Secure login for administrators.
- [cite_start]**CRUD Operations:** Add, View, Update, and Delete student records[cite: 4].
- **Search Functionality:** Search for students by their unique ID or Name.
- **Performance Tracking:**
  - Generate Grade System and Pass/Fail results.
  - Find the Class Topper and generate a Rank List.
  - Calculate Average Marks and view overall Class Statistics.
  - Identify students eligible for Scholarships.
- [cite_start]**Attendance System:** Mark and view daily student attendance[cite: 2].
- [cite_start]**Data Export:** Export student records to a `Student_Report.csv` file for easy viewing in Excel[cite: 3].

## 🛠️ Technologies & Concepts Used
- **Language:** Python 3
- **Storage:** File Handling (`.txt` files for raw data, `.csv` for reports)
- **Concepts:** Object-Oriented Programming (Classes & Static Methods), Data Parsing, Module Imports.

## 📂 Project Structure
- `main.py` - The entry point of the application containing the main menu loop.
- `student.py` - Contains the core `Student` class and logic for all operations.
- `csv_export.py` - Handles the logic for exporting student data to CSV format.
- [cite_start]`Students.txt` - Text file acting as a database for storing student details[cite: 4].
- [cite_start]`Attendance.txt` - Text file for recording daily attendance[cite: 2].
- [cite_start]`Admin.txt` - Text file storing admin login credentials.
